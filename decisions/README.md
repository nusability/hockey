# Architecture Decision Records

Dated, one-off technical decisions — the durable *why* that code cannot explain.
One file per decision: `NNNN-short-title.md` (e.g. `0001-two-native-codebases.md`).

## Template
```
# NNNN. <title>
Date: YYYY-MM-DD · Status: proposed | accepted | superseded by NNNN

## Context
<forces at play — what made this a decision>

## Decision
<what we chose>

## Consequences
<trade-offs, what this closes off>
```
